# Employee Data Cleaning and Analysis Using Excel

## Project Overview
This project focuses on cleaning, transforming, and analyzing employee data using Microsoft Excel. The objective was to improve data consistency and apply Excel functions to extract meaningful information and answer business-related questions.

## Tools Used
- Microsoft Excel

## Tasks Performed
1. Text Functions and Data Cleaning
- Extracted first and last names from the full name column.
- Combined first and last names to create email addresses.
- Calculated the character length of employee names.
- Standardized text using UPPER, LOWER, and PROPER functions.
- Removed extra spaces using the TRIM function.
- Converted department names into the required format.
2. Aggregate Functions
- Calculated total employee salaries using SUM.
- Calculated average salaries using AVERAGE.
- Counted employees using COUNTA.
- Calculated total salary for the Sales department using SUMIF.
- Calculated average salary for the HR department using AVERAGEIF.
- Calculated average salary for female employees in Lagos using AVERAGEIFS.
- Calculated total salary for Lagos employees with more than three years of experience using SUMIFS.
- Counted male employees in the Lagos location using COUNTIFS.
- Identified the maximum salary for employees in the IT department using MAXIFS.

  ## Project Objectives
- Improve data quality and consistency.
- Practice Excel text manipulation and aggregation techniques.
- Analyze salary distribution across departments and employee categories.
- Answer employee-related business questions using Excel formulas.

## Key Skills Demonstrated
- Data cleaning and standardization
- Text manipulation
- Logical and conditional analysis
- Aggregate functions
- Criteria-based calculations
- Employee and salary analysis

## Project Outcome
The project demonstrates the use of Excel functions to transform raw employee data into a cleaner, more consistent dataset and generate useful summaries for workforce and salary analysis.
